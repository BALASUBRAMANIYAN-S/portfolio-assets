# Portfolio Assets

Image, GIF and file assets used by my personal portfolio website. The portfolio loads these files from this repository.

## What is here

- Project screenshots and images (for example weather app, to-do app, QR generator, final year project)
- Profile and "about" images
- Feature and achievement photos
- Animated GIFs used in the portfolio
- Resume (CV)

## How to use

Link to a file with its raw GitHub URL:

```
https://raw.githubusercontent.com/BALASUBRAMANIYAN-S/portfolio-assets/main/<file-name>
```

## Notes

- Only keep files here that are meant to be public. Anything uploaded to a public repository can be viewed and downloaded by anyone.
- Large GIFs slow page loading. Compress them or convert them to short MP4 or WebP files when possible.
